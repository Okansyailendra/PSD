# Analisis Clustering

Bagian ini membahas proses analisis clustering pada dataset polutan. Analisis dilakukan dengan dua pendekatan yang berbeda untuk membandingkan hasil dan memahami karakteristik data lebih dalam:

1. **Clustering menggunakan Python (Kode)**: Menggunakan algoritma clustering dengan implementasi bahasa pemrograman Python di dalam Jupyter Notebook.
2. **Clustering menggunakan KNIME**: Memanfaatkan *tools* visual KNIME untuk merancang *workflow* clustering, baik dengan reduksi dimensi (PCA) maupun tanpa reduksi dimensi.

Silakan pelajari masing-masing pendekatan pada sub-bagian di bawah ini.
