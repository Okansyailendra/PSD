Selamat Datang di Mata Kuliah Proyek Sains Data (PSD)

Buku panduan dan materi interaktif yang dirancang untuk membantu memahami, merancang, dan mengimplementasikan proyek sains data.

Capaian Pembelajaran

  • Memahami siklus hidup proyek sains data, mulai dari pemahaman bisnis (business understanding) hingga deployment.
  • Mengumpulkan dan Membersihkan data dari berbagai sumber (API, web scraping, database).
  • Mengeksplorasi data menggunakan teknik Exploratory Data Analysis (EDA) yang mendalam.
  • Membangun model prediktif atau deskriptif menggunakan algoritma Machine Learning yang tepat.
  • Menyajikan hasil analisis dalam bentuk visualisasi data yang komunikatif dan interaktif.
  • Mendeploy model ke dalam aplikasi berbasis web untuk dapat digunakan oleh pengguna (end-user).

Prasyarat

  • Pemrograman Python (terutama penggunaan library pandas, numpy, dan matplotlib / seaborn).
  • Statistika & Probabilitas (konsep dasar distribusi, uji hipotesis, dan korelasi).
  • Dasar Machine Learning (pemahaman konsep regresi dan klasifikasi).

Struktur Pembelajaran

Tahap 1: Pengumpulan & Persiapan Data

Mempelajari teknik akuisisi data, penanganan missing values, outliers, dan transformasi data.

Tahap 2: Exploratory Data Analysis (EDA)

Teknik visualisasi data dan penggalian insight (wawasan) menggunakan berbagai plot statistik.

Tahap 3: Pemodelan Machine Learning

Implementasi model cerdas serta evaluasi dan optimasi model (hyperparameter tuning).

Tahap 4: Deployment & Presentasi

Mengemas hasil analisis ke dalam dashboard interaktif dan presentasi proyek.

Cara Menggunakan Buku Ini

Buku ini dibuat menggunakan Jupyter Book. Beberapa hal yang dapat Anda lakukan:

  • Membaca materi secara terstruktur dari panel navigasi di sebelah kiri.
  • Berinteraksi dengan kode: Anda dapat menjalankan notebook di awan (cloud) pada halaman tertentu.
  • Mengunduh: Anda dapat mengunduh halaman dalam format .ipynb (Jupyter Notebook) atau .pdf.
