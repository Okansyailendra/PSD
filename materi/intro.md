# 🚀 Selamat Datang di Mata Kuliah Proyek Sains Data (PSD)

Selamat datang di buku panduan dan materi interaktif untuk mata kuliah **Proyek Sains Data**. Buku ini disusun untuk membantu Anda dalam memahami, merancang, dan mengimplementasikan proyek sains data secara *end-to-end* yang sesuai dengan standar industri.

---

## 🎯 Capaian Pembelajaran

Setelah mengikuti mata kuliah ini, Anda diharapkan mampu:
1. **Memahami** siklus hidup proyek sains data, mulai dari pemahaman bisnis (business understanding) hingga *deployment*.
2. **Mengumpulkan dan Membersihkan** data dari berbagai sumber (API, web scraping, database).
3. **Mengeksplorasi** data menggunakan teknik Exploratory Data Analysis (EDA) yang mendalam.
4. **Membangun** model prediktif atau deskriptif menggunakan algoritma Machine Learning yang tepat.
5. **Menyajikan** hasil analisis dalam bentuk visualisasi data yang komunikatif dan interaktif.
6. **Mendeploy** model ke dalam aplikasi berbasis web untuk dapat digunakan oleh pengguna (end-user).

---

## 🛠️ Prasyarat

Sebelum memulai mata kuliah ini, pastikan Anda telah memiliki pemahaman dasar mengenai:
- **Pemrograman Python** (terutama penggunaan *library* `pandas`, `numpy`, dan `matplotlib` / `seaborn`).
- **Statistika & Probabilitas** (konsep dasar distribusi, uji hipotesis, dan korelasi).
- **Dasar Machine Learning** (pemahaman konsep regresi dan klasifikasi).
